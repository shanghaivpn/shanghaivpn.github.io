1. 什么是 Shadowrocket？为什么选择它？

1.1 Shadowrocket 简介

Shadowrocket 是一款专为 iOS 设备设计的代理工具，可以帮助用户在 iPhone、iPad 上建立加密代理连接，突破网络限制，保护个人隐私。

不同于普通 VPN 软件，Shadowrocket 提供了更丰富的自定义功能，用户可以根据需求灵活配置代理规则，实现智能分流，让某些应用或网站走代理，而其他流量保持直连。

1.2 为什么选择 Shadowrocket？它有哪些优势？

✅ 高速稳定：支持 UDP 转发，提供低延迟的网络体验，适合观看流媒体、游戏加速等需求。

✅ 多协议支持：兼容 Shadowsocks、ShadowsocksR、Vmess（V2Ray）、Trojan、SOCKS5、HTTP(S) 等多种代理协议，适应不同使用场景。

✅ 智能分流：用户可以设定代理规则，比如让国内网站直连，国外网站走代理，既节省流量又提升访问速度。

✅ 强大日志系统：提供详细的网络日志，方便用户分析代理连接状态，进行故障排查。

✅ 稳定可靠：作为 App Store 上的正规上架应用，Shadowrocket 相较于一些非官方代理工具来说更加安全、稳定，不易失效。

⚠ 重要提示：Shadowrocket 不是免费应用，目前在 App Store 的售价约为 $2.99（美区 Apple ID 购买）。虽然是付费软件，但其稳定性和功能性远超许多免费代理工具，因此长期使用的用户会觉得物超所值。

6️⃣ 完成验证并登录 App Store

2.3 切换 Apple ID 到美区

1️⃣ 打开 iPhone / iPad 的“设置”
2️⃣ 点击 Apple ID 头像 > 媒体与购买 > 查看账户
3️⃣ 进入“国家/地区”选项，选择“美国”

FAQ

Sing-box 如何实现流量精细分流？
通过定义 routing 规则和策略组，Sing-box 可以根据域名、IP、端口或协议类型精细分流流量。例如视频走高速节点，网页走备用节点，实现流量优化和网络加速。
如何将 Clash 节点导入到 Sing-box？
Sing-box 支持从 Clash 配置文件中导入节点。用户只需将 YAML 文件放入配置目录或通过命令导入即可。系统会自动解析规则组和节点信息，简化迁移过程。
PassWall2 如何定时自动更新节点？
可在计划任务中添加命令 `passwall update` 并设定时间间隔，例如每日凌晨自动更新。这样可确保节点信息实时同步，避免旧节点失效影响连接体验。
WinXray 如何保证视频流畅播放？
WinXray 会结合延迟检测和策略组选择最佳节点转发视频流量。通过自动切换低延迟节点，可保证在线视频播放顺畅，减少卡顿和缓冲，提高整体体验。
QuantumultX 的重写规则可实现哪些功能？
QuantumultX 的重写规则支持请求头修改、响应内容修改、广告屏蔽及自动跳转。结合脚本可实现自动签到、流量统计和定制化网络访问，极大增强客户端灵活性。
Surfboard 的节点策略组如何提升使用体验？
策略组可将节点按延迟、用途或地理位置分类，通过规则自动选择最优节点。用户无需手动切换节点即可获得最佳速度和稳定性，提高浏览和观看流媒体的体验。
V2Ray 的 TCP + TLS 模式适合什么场景？
TCP + TLS 模式可模拟 HTTPS 流量，增强抗封锁能力。适合网络封锁严格的环境，通过策略组选择最佳节点，可保证访问速度和连接稳定性，尤其适用于网页浏览和视频播放。
Shadowsocks 密码泄露后应如何应对？
立即更改服务端密码与相应的端口，检查服务器是否存在异常连接或 root 活动，查看日志并封禁可疑 IP。若使用多人共享节点，建议为每个用户单独分配独立端口与密码以降低风险传播。
VLESS + XTLS 模式相比普通 VLESS 有哪些优势？
XTLS 模式减少冗余加密开销，提高传输效率，并在多连接高负载环境下表现更佳。同时仍保持 TLS 安全性，结合策略组可实现高性能和高隐蔽性的双重优势。
SSR 的加密方式推荐使用哪种？
SSR 支持多种加密方式，如 aes-256-cfb、chacha20、rc4-md5 等。建议优先选择 chacha20 系列算法，在移动设备上性能更佳，同时具有较强的安全性。
